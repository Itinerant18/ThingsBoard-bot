## Skill: graphify

Use the `/graphify` skill to explore the codebase structure, architecture, and relationships. Graphify converts code into a persistent knowledge graph with community detection, god nodes, and semantic clustering.

### When to use graphify

- **Architecture overview**: Understanding high-level codebase structure and module dependencies
- **Finding code**: Locating functions, classes, files by semantic search or keyword
- **Impact analysis**: Understanding what changes when you modify a file or function
- **Code organization**: Identifying cohesion, coupling, and architectural patterns
- **Relationship discovery**: Finding callers, dependencies, cross-file interactions

### Workflow

1. Type `/graphify` to build or update the knowledge graph
2. Use the generated HTML report and JSON output in `graphify-out/`
3. Query the graph for specific questions about code relationships and structure
