Today's Work:

1. Diagnosed the Regional Scope Leak (Bug Report Review)
Reviewed the regional-filtering & status-sync bug report and traced the issue end-to-end in code. Found the documented root cause (a zone-name fallback) was a red herring: the real leak was that the branch-index retrieval path skipped regional scoping entirely, so a region-scoped user (e.g. Jharkhand NBG) could see the whole bank inventory (~100 branches) instead of their own. Confirmed the leak only surfaces when two-step fetch is enabled (the direction the codebase is moving toward).

2. Fixed the Regional Branch-List Scope Leak
Built one shared, region-aware scope filter (RegionalScopeUtil) now used by both retrieval paths so they can't diverge and leak. Made it fail closed — when a token explicitly names a region that can't be resolved, it returns nothing instead of the full inventory. Removed the old broken zone-only fallback and the duplicated logic. Added unit tests.

3. Fixed the Region-Name Abbreviation Mismatch (live test finding)
Live-tested with a real Jharkhand NBG token: the bot returned 0 branches because the token's region "NBG JHARKHAND" didn't match the hierarchy node named "NBG JH". Added abbreviation tolerance (prefix match, guarded so it can't over-match) so "NBG JHARKHAND" correctly resolves to "NBG JH" — and not to sibling regions like NBG EAST.

4. Added the "Unknown" Status Bucket
The global overview previously counted branches with no status attribute as Offline, over-stating the offline total. Split these into their own "Unknown" bucket so the answer reads "X Online | Y Offline | Z Unknown" (the Unknown part only shows when there are any), consistent with the strict _sts rule.

5. Validated Behaviour Against the Backup Data
Confirmed against thingsboard_devices_backup.json: NBG JH has exactly 21 branches (2 Online, 15 Offline, 4 with no gateway_sts → Unknown). Identified that the replay step's default 7-day window silently drops the months-old snapshot events, which is why all 21 first showed Unknown — fixed operationally by replaying with a wide start date.

6. Made Multi-Bank Hierarchy Labeling Generic
Reviewed the differing hierarchies of all 10 banks (BOI, BOB, SBI, Canara, IB, PNB, UBI, CBI, IOB, UCO). The importer only understood BOI's NBG/ZO levels and mislabeled every other bank's levels (RO/CO/LHO/RBO). Reworked it to read each level from its own name code (RO/CO/LHO/RBO/ZO/NBG/FGMO), so all banks' levels label correctly at any depth with no per-bank hardcoding. Added tests. Confirmed the expected full_path format with the team for when the source data is corrected.

7. Stopped Tracking Local Data Folder
Moved the Thingsboard-Data backup folder out of version control (.gitignore) so ad-hoc data changes no longer churn the repo.
